# ARGUS BURP POLICY

Burp is the primary manual web/API evidence and validation layer.

Burp project path:

`~/BurpSuite/<Program Name>/`

Argus should use Burp for:

- sitemap building
- request capture
- Repeater validation
- Comparer response analysis
- Organizer notes
- Logger review
- low-noise manual replay
- evidence capture

Burp Intruder should only be used in low-rate/manual-style mode unless scope permits more.

Burp evidence should be exported, summarized, or linked into the target folder.

Burp project files should be stored under:

`~/BurpSuite/<Program Name>/`

Target notes should link to the relevant Burp project path.
